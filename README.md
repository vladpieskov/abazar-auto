# ABAZAR Auto Accessories - E-Commerce Store & Admin Portal

Plateforme e-commerce professionnelle pour **ABAZAR Auto Accessories (Agadir, Maroc)** avec thème Black & Red, catalogue de pièces auto, panier avec bon de commande WhatsApp direct et panneau d'administration sécurisé.

---

## 🚀 Déploiement Gratuit sur Vercel (En 2 Minutes)

### Option 1 : Déploiement via GitHub (Recommandé)
1. Créez un nouveau dépôt sur [GitHub](https://github.com/new) (ex: `abazar-auto`).
2. Poussez ce dossier sur GitHub :
   ```bash
   git init
   git add .
   git commit -m "Initial commit ABAZAR store"
   git branch -M main
   git remote add origin https://github.com/VOTRE_PSEUDO/abazar-auto.git
   git push -u origin main
   ```
3. Rendez-vous sur [Vercel](https://vercel.com) et cliquez sur **« Add New... » > « Project »**.
4. Importez votre dépôt GitHub `abazar-auto` et cliquez sur **« Deploy »**.
5. Votre boutique sera instantanément en ligne avec une adresse du type `abazar-auto.vercel.app` et certificat SSL gratuit !

---

### Option 2 : Déploiement Direct via Vercel CLI
Dans le terminal dans ce dossier :
```bash
npx vercel
```
Suivez les 3 questions à l'écran (appuyez sur Entrée) et votre site sera en ligne immédiatement !
